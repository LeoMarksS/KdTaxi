🧱 STACK OBRIGATÓRIA
Frontend Mobile: React Native + Expo
Backend: Node.js + Express (rodando no Replit)
Tempo real: Socket.io
Armazenamento: SQLite ou JSON simples
Notificações:
Push via Expo Notifications
Sons locais no app
